# Журнал тренера

Веб-приложение для частного преподавателя: посещения, абонементы и оплаты в одном экране занятия. Сделано по макетам из Figma, раздел «Приложение / UI-kit / связанные экраны».

Открыть: https://eldargaliamov.github.io/trainer-journal/

## Установка на телефон

- **iPhone:** откройте ссылку в Safari, нажмите «Поделиться», затем «На экран “Домой”».
- **Android:** откройте ссылку в Chrome и нажмите «Установить» в подсказке или в меню браузера.

После установки журнал открывается на весь экран, как обычное приложение, и работает без интернета.

## Что умеет

- Отметка пришедших и выбор учёта: абонемент, разовое занятие, новый абонемент.
- Оплата наличными, переводом или «ещё не оплачено».
- Добавление и редактирование занятий (в том числе каждую неделю) и учеников.
- Свайп от левого края возвращает назад.
- Данные хранятся на устройстве. Демо-данные можно восстановить на вкладке «Ученики».
