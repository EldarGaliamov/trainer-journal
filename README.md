# Журнал тренера

Веб-прототип приложения для частного преподавателя: посещения, абонементы и оплаты в одном экране занятия.

Открыть: https://eldargaliamov.github.io/trainer-journal/

- Отметка пришедших и выбор учёта: абонемент, разовое занятие, новый абонемент.
- Оплата наличными, переводом или «ещё не оплачено».
- Добавление и редактирование занятий (в том числе каждую неделю) и учеников.
- Данные хранятся в браузере. Демо-данные можно восстановить на вкладке «Ученики».

Лучше всего открывать с телефона и добавить на экран «Домой».
